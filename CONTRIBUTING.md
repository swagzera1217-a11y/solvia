# Contributing

Use Node.js 20 or later. Run `npm test` and `npm run check` before proposing changes. No dependency installation is needed.

Keep changes focused and document user-visible behavior. Verify affected screens at desktop and mobile widths. Check source failure behavior as well as the successful path.

- Preserve the Solana purple/green palette and compact typography.
- Distinguish public data, illustrative motion and local simulation.
- Never label a draft or paper position as an on-chain transaction.
- Add signing only through a separately designed, reviewable execution flow.
- Do not commit credentials, wallet exports, recovery phrases or private user data.

Use issues for non-sensitive reproducible bugs. Include the route, expected behavior and browser version. Do not include secrets in an issue or screenshot.
